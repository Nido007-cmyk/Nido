# Swahili glossary · Kamusi

Every wording decision the reviewer makes lives here, so it
sticks across the whole app: a term chosen once is used the
same way everywhere.

How to add one: a word or phrase in English, the Swahili form
that should always be used, and a line about why if it matters
("this is what people actually say in Kenya", "the other word
is only used in books", and so on). You can edit this file
directly, or just mention the decision in a Note in any review
file and we will write it down here.
